# Cancer Detection Dataset with Pandas

This repository contains a dataset and a Jupyter notebook that demonstrates cancer detection using machine learning and data analysis with Pandas. The notebook covers various aspects of data preprocessing, exploratory data analysis (EDA), and model building for predicting cancer diagnosis.

## Project Overview

The project aims to detect cancer from medical data using machine learning techniques. The dataset contains several features related to cancer diagnosis, such as tumor size, age, and type of cancer. The notebook guides you through the steps of preprocessing the data, training machine learning models, and evaluating their performance.

## How to Run the Notebook

To run the notebook, follow the steps below:

### 1. Open Google Colab

- Visit [Google Colab](https://colab.research.google.com/).

### 2. Download the Dataset and Notebook

- Download the `cancer_data.csv` dataset and the `assignment.ipynb` notebook from this repository.

### 3. Upload Files to Colab

- After opening Google Colab, upload the notebook and dataset by clicking on the **Upload** option in the **File** tab.

### 4. Run Each Cell

- Once the files are uploaded, run each cell in the notebook one by one to perform the data analysis, model training, and evaluation.
- You can do this by selecting **Run** in the toolbar for each cell.

### 5. (Alternative) Run All Cells at Once

- Alternatively, you can run all cells at once by selecting **Runtime** > **Run All** (or press `Ctrl + F9`).

Once you have run all cells, you will be able to see the results of data analysis and model performance metrics.

## Features

- **Data Preprocessing**: Handling missing values, encoding categorical data, and scaling features.
- **Exploratory Data Analysis (EDA)**: Visualizing distributions and correlations in the dataset.
- **Machine Learning Models**: Using algorithms like Logistic Regression, Random Forest, and Support Vector Machines for cancer detection.
- **Model Evaluation**: Measuring model performance with metrics such as accuracy, precision, recall, and F1-score.

## Dataset

The dataset used in this project contains the following columns:

- **Age**: Age of the patient
- **Tumor Size**: Size of the tumor (in centimeters)
- **Cancer Type**: Type of cancer (e.g., Breast Cancer, Lung Cancer, etc.)
- **Diagnosis**: Whether the patient has cancer or not (target variable)

You can download the dataset from [here](https://www.kaggle.com/).
